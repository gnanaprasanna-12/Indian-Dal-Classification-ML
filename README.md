# Indian Dal and Pulses Image Classification Using Machine Learning

## Project Overview

This project focuses on identifying different types of Indian dals and pulses from images using Machine Learning classification algorithms.

The main objective is to classify dal images into their respective categories using image preprocessing and machine learning techniques.

## Dataset

The project includes five categories of Indian dals:

- Chana
- Masur
- Moong
- Toor
- Urad

## Technologies Used

- Python
- Jupyter Notebook
- OpenCV
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Project Workflow

1. Dataset Collection
2. Image Loading
3. Image Preprocessing
4. Image Resizing
5. Conversion of Images into Numerical Arrays
6. Feature and Target Separation
7. Train-Test Split
8. KNN Classification
9. Decision Tree Classification
10. Model Evaluation
11. Prediction on New Images

## Machine Learning Algorithms

### 1. K-Nearest Neighbors (KNN)
Used to classify dal images based on their nearest training samples.

### 2. Decision Tree Classifier
Used to classify images by learning decision rules from the training data.

## Model Evaluation

Both algorithms are evaluated using accuracy scores and their performance is compared.

| Algorithm | Accuracy |
|---|---|
| KNN | 0.63 |
| Decision Tree | 0.781 |

## Prediction

The trained model is used to predict the category of a new, unseen dal image.

## Project Objective

To gain practical knowledge of image preprocessing, feature extraction, machine learning classification and model evaluation.
